# 栄養の基準値と判定しきい値

出典の考え方は「日本人の食事摂取基準(2020/2025年版)」および「健康日本21」の野菜摂取目標。
献立提案という用途に合わせて、丸めた実務値として載せている。
医療目的(腎臓病のたんぱく制限、糖尿病の指示エネルギーなど)には使えない。
利用者が疾患による食事制限に言及したら、この表で押し切らず医師・管理栄養士の指示を優先するよう伝えること。

## 目次
1. 推定エネルギー必要量
2. 三大栄養素の目標量(%エネルギー)
3. その他の栄養素の基準
4. 世帯合算のしかた
5. 判定しきい値

---

## 1. 推定エネルギー必要量 (kcal/日、身体活動レベルII「ふつう」)

| 年齢 | 男性 | 女性 |
|---|---|---|
| 1-2 | 950 | 900 |
| 3-5 | 1300 | 1250 |
| 6-7 | 1550 | 1450 |
| 8-9 | 1850 | 1700 |
| 10-11 | 2250 | 2100 |
| 12-14 | 2600 | 2400 |
| 15-17 | 2800 | 2300 |
| 18-29 | 2650 | 2000 |
| 30-49 | 2700 | 2050 |
| 50-64 | 2600 | 1950 |
| 65-74 | 2400 | 1850 |
| 75+ | 2100 | 1650 |

身体活動レベル補正: I(低い=座位中心) ×0.86 / II(ふつう) ×1.00 / III(高い=立ち仕事・運動習慣) ×1.14

妊娠期は初期+50 / 中期+250 / 後期+450、授乳期は+350 を加算する。

## 2. 三大栄養素の目標量(総エネルギーに占める割合)

| 栄養素 | 目標範囲 | 換算 |
|---|---|---|
| たんぱく質 | 13-20%E (65歳以上は15-20%E) | 1g = 4kcal |
| 脂質 | 20-30%E | 1g = 9kcal |
| 炭水化物 | 50-65%E | 1g = 4kcal |

献立の目標値としては中央値付近(P 16%E / F 25%E / C 59%E)を採り、
判定は範囲に入っているかで見る。中央値ぴったりを要求すると献立が組めなくなる。

**たんぱく質の推奨量(下限として併用)**: 男性18-64歳 65g / 65歳以上 60g、女性18歳以上 50g。
%Eで足りていても実量がこれを下回るなら不足として扱う(低エネルギー設定の人で起きやすい)。

## 3. その他の栄養素の基準 (1日あたり)

| 項目 | 男性 | 女性 | 性質 |
|---|---|---|---|
| 食物繊維 | 21g以上 (65歳以上 20g) | 18g以上 (65歳以上 17g) | 多いほど良い |
| 食塩相当量 | 7.5g未満 | 6.5g未満 | **上限**。超過は減点 |
| カルシウム | 750mg (18-29歳 800 / 75歳以上 700) | 650mg (75歳以上 600) | 推奨量 |
| 鉄 | 7.5mg | 10.5mg (月経なし 6.5mg) | 推奨量 |
| ビタミンC | 100mg | 100mg | 推奨量 |
| 野菜 | 350g以上 (うち緑黄色野菜120g以上) | 同左 | 目標量 |

小児は上記の成人値をエネルギー比で按分してよい(厳密ではないが献立用途では実害が出ない)。
ただし食塩だけは按分せず、小児は 1-2歳 3.0g / 3-5歳 3.5g / 6-7歳 4.5g / 8-9歳 5.0g /
10-11歳 6.0g / 12歳以上 成人値 を上限とする。塩分は体格に対して過剰になりやすい。

## 4. 世帯合算のしかた

世帯の目標は**全員分の単純合計**でよい。エネルギー・たんぱく質・食物繊維・カルシウム・鉄・
ビタミンC・野菜量・食塩上限、すべて人数分を足す。

ただし献立を作るときの「1人前×人数」は成人基準で数える。子どもは成人の0.5〜0.8人前しか食べないが、
そこまでモデル化すると分量調整が煩雑になり、かつ多めに作った分は翌日に回るので実害が小さい。
**摂取量の判定だけは実際の目標合計で行う**ことで、辻褄は合う。

## 5. 判定しきい値

達成率 = 実際の摂取量 ÷ 目標値。1日合計と週平均の両方で見る。

| 栄養素 | 良好 | 注意 | 要改善 |
|---|---|---|---|
| エネルギー | 90-110% | 80-90% / 110-120% | <80% / >120% |
| たんぱく質 | 100%以上かつ%Eが13-20%内 | 85-100% | <85% |
| 脂質(%E) | 20-30%E | 18-20 / 30-33%E | <18 / >33%E |
| 炭水化物(%E) | 50-65%E | 45-50 / 65-70%E | <45 / >70%E |
| 食物繊維 | 100%以上 | 70-100% | <70% |
| 食塩 | 100%以下 | 100-120% | >120% |
| カルシウム | 100%以上 | 70-100% | <70% |
| 鉄 | 100%以上 | 70-100% | <70% |
| ビタミンC | 100%以上 | 70-100% | <70% |
| 野菜量 | 100%以上 | 70-100% | <70% |

**1日単位で全項目を良好にするのは非現実的**。週平均で良好、かつ要改善の日が週1日以下なら
その献立は合格として扱ってよい。完璧を求めて毎日を作り直すと、レシピの多様性が犠牲になり
「毎日ほうれん草のおひたし」のような献立が出来上がる。これは栄養的には正しくても続かない。

食塩だけは例外で、日単位でも上限を守る方向に寄せる。週平均で帳尻を合わせても
「今日はラーメンで8g」という日が繰り返されるのは避けたい。
